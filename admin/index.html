ورود فقط با توکن GitHub — همین توکن هم رمز است و هم دسترسی.
توکن را چطور بسازم؟
  1. در GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access ← فقط Only select repositories و مخزن love_kill_me
  3. Permissions → Repository permissions → Contents: Read and write
  4. (اختیاری) Pages: Read-only برای نمایش وضعیت انتشار
  5. توکن را کپی کن و همین‌جا بچسبان. توکن فقط به api.github.com فرستاده می‌شود و روی هیچ سروری ذخیره نمی‌شود.
